# George Davis | AI, Data & Digital Services

A responsive, single-page freelance portfolio designed for GitHub Pages.

## Included
- `index.html` — complete responsive portfolio website
- `assets/` — certificate images extracted from the two supplied PDF certificates

## Before publishing (important)
1. Open `index.html` in a text editor.
2. Search for `YOUR_EMAIL@example.com` and replace both occurrences with your real email address.
3. Replace the LinkedIn and GitHub placeholder links with your profile URLs.
4. Replace the illustrated profile placeholder with your own professional photograph when ready. The placeholder is CSS-based, so no image file is required.
5. Add your Microsoft IT Helpdesk Specialist certificate image in `assets/` and update the third certificate card in `index.html`.
6. Review the biography and service descriptions to ensure they accurately reflect the services you are ready to deliver.

The project cards are clearly labelled as demonstration concepts, not paid client projects. Replace them with verified work samples as you complete projects.

## Publish on GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `george-davis-portfolio`.
2. Unzip this package on your computer.
3. Upload `index.html`, the `assets` folder, and this `README.md` to the repository's root (not inside another nested folder).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish. Your website address will be:
   `https://YOUR-GITHUB-USERNAME.github.io/george-davis-portfolio/`
   Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.
8. Whenever you update the files in the repository, GitHub Pages republishes the site.

## Contact form
GitHub Pages is static hosting. This version uses a `mailto:` form: it opens the visitor's email application and does not save submissions on the website. Set your real email address in the JavaScript before publishing. For a form that submits without opening an email application, connect a form service or add a small backend.

## Custom domain (optional)
You can later purchase a domain and connect it through **Settings → Pages → Custom domain**. Enable HTTPS after DNS is configured.
